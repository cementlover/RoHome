# RoHome
Roblox browser extension to hide homepage and sidebar clutter.
Currently compatible with Chrome and Brave. Firefox untested.

# Installation
Step 1: Open the extension manager in your browser. Usually done by clicking your extenions button in the top right, then clicking "Advanced" or "Manage extensions".

Step 2: Enable developer mode. Usually a toggle in the top right/left depending on browser.

Step 3: Click "Load unpacked" and open the folder downloaded from the repository. Ensure the extension is enabled.

# Using the extension
You can toggle what to hide and what to show by clicking the extension in the top right to open the menu. The Roblox website updates automatically, but if some components take too long to unload, you can refresh the page to manually update them.
